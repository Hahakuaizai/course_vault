# 课程库

把散落在桌面、DeskBox 里的课程资料（实验报告、作业、课件）集中登记到一个界面里，按课程分类、快速搜索、直接预览。

**核心原则：不动文件。** 默认只登记路径，原文件留在原处；需要时也可以把文件复制一份进软件保存，原文件同样不受影响。

---

## 启动

```bash
cd course-vault
npx electron .
```

或双击 `启动.bat`。

## 功能

### 多级目录
- 目录可以无限嵌套，课程、项目、收藏夹都行
- 侧栏直接**拖拽**目录：拖到某个目录上 = 成为它的子目录；拖到空白 = 回到顶层；拖到行上/下缘 = 同级排序
- 右侧「更多」菜单同样可以新建子目录、重命名、移到顶层、删除
- 删除目录会连同子目录一起移除（磁盘原文件不受影响）
- 同一层级下不允许重名，也不允许把目录拖进自己的子孙里

### 导入
- 支持选择多个文件，或整个文件夹（递归扫描）
- **两种保存方式**：
  - **链接**（默认）：只记路径，原文件一动不动
  - **入库**：复制一份进软件数据目录，之后原文件删了也能看
- 文件卡片上带「入库」角标，右键可在两种方式之间随时互转
- 遇到重复文件会弹窗，让你当场选**跳过 / 替换 / 允许重复**

### 预览

| 格式 | 方式 |
|---|---|
| PDF | 内嵌渲染，可翻页缩放 |
| 图片 | 直接显示，网格里带缩略图 |
| 视频 / 音频 | 内嵌播放 |
| Word (.docx) | 解析为 HTML，表格和中文完整还原 |
| Excel (.xlsx) | 多工作表切换查看 |
| PPT (.pptx) | 按页提取文字（版式需用 Office/WPS 查看） |
| Markdown | 渲染 + 代码高亮 |
| 代码 / 纯文本 | 语法高亮 |

`.doc` / `.ppt` 等旧格式无法内嵌解析，会提示用系统程序打开。

### 编辑
- Markdown、代码、纯文本支持**内置编辑**：点铅笔图标进入，`Ctrl+S` 保存
- 保存前自动备份旧版本到「备份文件夹」
- Word / Excel / PPT 等复杂格式请用「用其他应用打开」，改完回到软件即可看到新内容

### 搜索
- **名称**：按文件名实时搜索
- **内容**：连文件正文一起搜（txt / md / 代码 / csv / json 等文本类），命中处会高亮片段
- 搜索始终在全库范围内进行，不受当前所在目录限制
- 可按类型筛选：文档 / 图片 / 音视频 / 代码 / 其他

### 回收站
- 删除目录或文件时弹窗选择：**放进回收站** / **彻底删除**
- 回收站按「删除批次」整条记录，可一次还原整批
- 入库文件的副本会被移到 `.trash` 子目录暂存，还原时移回原处
- 支持单条彻底删除和清空回收站

### 右键菜单
预览、用其他应用打开、在文件夹中显示、复制进软件保存 / 改回链接、移动到其他目录、从库中移除。

Claude 风格：暖纸白底 + 陶土橙强调色，标题用衬线字体，低饱和细边框。

## 数据存放

| 内容 | 位置 |
|---|---|
| 索引数据 | `%APPDATA%\课程库\vault-data.json` |
| 入库文件副本 | 默认 `%APPDATA%\课程库\files\`，**可在「设置 → 数据」改到其他盘** |
| 编辑备份 | `%APPDATA%\课程库\backups\` |

索引数据是纯 JSON，可以直接备份或手动查看。没有后端服务、没有数据库进程，关掉软件就什么都不跑。

入库位置支持迁移：在设置里点「更改」选新文件夹，会问你要不要连同已有文件一起搬过去。

## 技术栈

- Electron 45
- 原生 HTML / CSS / JS，无前端框架
- mammoth（Word）、xlsx（Excel）、jszip（PPT）、marked（Markdown）、highlight.js（代码高亮）
- 自定义 `vault://` 协议安全地提供文件给渲染进程，只允许访问已登记的文件

---

## 已知限制

- PPT 只能提取文字，看不到排版、图片、动画
- `.doc` / `.ppt` 旧格式不支持内嵌预览
- 超过 2MB 的文本文件不做内嵌预览
- 内容搜索只覆盖文本类文件（PDF / Word / PPT 内部文字暂不索引），单文件最多读 512KB
- 链接方式的记录是绝对路径，文件被移动或重命名后会显示「已丢失」（可重新导入，或改用入库方式）
